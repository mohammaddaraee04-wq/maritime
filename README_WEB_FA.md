# Maritime Knowledge Base — نسخه پیش‌نمایش وب 0.2.0

این پوشه برای انتشار نسخه وب روی Streamlit Community Cloud آماده شده است.

## چه چیزی در نسخه وب فعال است؟

- صفحه خانه فارسی
- جست‌وجوی دوطرفه فارسی و انگلیسی در مدخل‌های نمونه
- نمایش ترجمه، تعریف، توضیح، مثال و وضعیت اعتبار
- نمایش واضح اینکه مدخل‌های نمونه «پیش‌نویس» هستند

## چه چیزی فعلاً غیرفعال است؟

- افزودن و ویرایش اصطلاحات
- بارگذاری PDF و اسناد
- پنل مدیریت عمومی
- هوش مصنوعی و RAG

این محدودیت عمدی است. Streamlit Community Cloud تضمین نمی‌کند فایل‌های تولیدشده در فضای محلی برنامه ماندگار بمانند. به همین دلیل، تا زمانی که پایگاه داده و فضای ذخیره‌سازی دائمی وصل نشده‌اند، نسخه عمومی فقط‌خواندنی است.

## انتشار رایگان در وب

### پیش‌نیاز

- حساب GitHub
- حساب Streamlit Community Cloud
- فایل‌های همین پوشه در یک مخزن GitHub

### مراحل

1. به https://github.com برو و وارد حساب خودت شو.
2. یک مخزن جدید بساز؛ نام پیشنهادی `maritime-knowledge-base` است.
3. محتویات این پوشه را در ریشه مخزن بارگذاری کن. فایل `streamlit_app.py` باید در ریشه باشد.
4. به https://share.streamlit.io برو و با GitHub وارد شو.
5. گزینه **Create app** را بزن.
6. مخزن، شاخه `main` و فایل اصلی `streamlit_app.py` را انتخاب کن.
7. گزینه **Deploy** را بزن.
8. پس از ساخت، Streamlit یک نشانی با دامنه `streamlit.app` می‌دهد که می‌توانی با مرورگر باز کنی و به اشتراک بگذاری.

راهنمای رسمی انتشار: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app

## نکات مهم قبل از انتشار عمومی

- هیچ فایل محرمانه، قرارداد، سند دارای محدودیت دسترسی یا کتاب دارای حق نشر را در مخزن عمومی قرار نده.
- در نسخه فعلی فقط سه مدخل نمونه قرار دارد و هر سه پیش‌نویس‌اند؛ برای استفاده تخصصی باید با منابع معتبر بازبینی شوند.
- Community Cloud برنامه‌های بدون ترافیک را پس از ۱۲ ساعت به خواب می‌برد؛ بازدیدکننده بعدی می‌تواند آن را بیدار کند.
- فایل‌های محلی برنامه در Community Cloud ماندگاری تضمین‌شده ندارند. داده‌های واقعی نباید در این نسخه ثبت شوند.
- طرح رایگان Supabase می‌تواند پایگاه داده PostgreSQL دائمی‌تری برای مرحله بعد فراهم کند، اما محدودیت حجم و توقف پروژه غیرفعال دارد؛ پشتیبان‌گیری جداگانه لازم است.

## معماری پیشنهادی نسخه کامل آنلاین

- رابط وب: Streamlit یا در مرحله محصولی‌تر، React/Next.js
- پایگاه داده: PostgreSQL (مثلاً Supabase)
- نگهداری فایل‌ها: فضای Object Storage جداگانه
- مدیریت دسترسی: ورود مدیر و نقش‌های کاربری
- موتور جست‌وجو: Full-text + Semantic Search
- هوش مصنوعی: RAG فقط بر اساس منابع دارای شناسه و شماره صفحه

تا پیش از اتصال پایگاه داده پایدار و احراز هویت مدیر، قابلیت‌های تغییردهنده داده در نسخه عمومی فعال نشوند.
