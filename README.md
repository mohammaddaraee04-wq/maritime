# پیش‌نمایش کوچک Maritime Knowledge Base

این صفحه یک نمونه ارزیابی رابط کاربری است و شامل دقیقاً **یک منبع و سه اصطلاح** است.

## واژگان نمونه
- Draft — آبخور کشتی
- Ballast — بالاست / ماده تعادل
- Bow — دماغه کشتی

## منبع
National Vessel Documentation Center (NVDC), U.S. Coast Guard (USCG), *Commonly Used Terms, Definitions and Abbreviations*, نام فایل با شناسه بازنگری 12-21.

[مشاهده سند اصلی (PDF)](https://www.dco.uscg.mil/Portals/9/DCO%20Documents/NVDC/COMMONLY%20USED%20TERMS%2C%20DEFINITIONS%20AND%20ABBREVIATIONS%20W%20HEADER%20REV%2012-21.pdf)

از صفحه اول سند سه عبارت کوتاه انگلیسی به‌عنوان شاهد ثبت شده‌اند. ترجمه‌های فارسی، مثال‌ها و نکات آموزشی برای نمایش نمونه تدوین شده‌اند و باید پیش از استفاده حرفه‌ای توسط متخصص دریایی بازبینی شوند. این منبع واژه‌نامه عمومی دریایی است و به‌تنهایی مرجع جامع مهندسی کشتی نیست.

## امکانات قابل آزمایش
- جست‌وجوی زنده فارسی و انگلیسی
- انتخاب بین سه اصطلاح
- نمایش تعریف، نکته کاربردی، مثال و شاهد منبع
- نمایش مشخصات سند و فرایند ورود اطلاعات
- چیدمان واکنش‌گرا برای صفحه‌نمایش کوچک

## محدودیت‌های نمونه
این صفحه یک فایل HTML ایستا است. داده‌ها داخل فایل قرار دارند؛ بانک اطلاعاتی زنده، پنل بارگذاری سند، استخراج خودکار، OCR، حساب کاربری، ذخیره تغییرات و هوش مصنوعی در این نمونه فعال نیستند.

## اجرای محلی
فایل `index.html` را با مرورگر باز کنید. نصب نرم‌افزار لازم نیست.
