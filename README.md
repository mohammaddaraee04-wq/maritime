# پیش‌نمایش کوچک Maritime Knowledge Base

این نسخه برای ارزیابی تجربه کاربری و شیوه ارائه واژگان دریایی ساخته شده است و دقیقاً شامل **یک منبع و سه اصطلاح** است.

## منبع یگانه

National Vessel Documentation Center (NVDC), U.S. Coast Guard (USCG), *Commonly Used Terms, Definitions and Abbreviations*. نسخه درج‌شده داخل سند: 11/2021.

[مشاهده سند PDF در وب‌سایت USCG](https://www.dco.uscg.mil/Portals/9/DCO%20Documents/NVDC/COMMONLY%20USED%20TERMS%2C%20DEFINITIONS%20AND%20ABBREVIATIONS%20W%20HEADER%20REV%2012-21.pdf)

## سه مدخل این نمونه

1. **Draft — آبخور کشتی**
2. **Ballast — بالاست؛ ماده تعادل**
3. **Bow — دماغه کشتی؛ سینه کشتی**

برای هر مدخل، معادل فارسی، تعریف، نکته تخصصی، مثال انگلیسی و ترجمه فارسی، شماتیک آموزشی و شاهد انگلیسی همراه شماره صفحه نمایش داده می‌شود. داده‌های تلفظ و IPA در منبع انتخاب‌شده موجود نیست؛ بنابراین این نمونه آن‌ها را جعل نمی‌کند.

## امکانات قابل آزمایش

- جست‌وجوی زنده فارسی و انگلیسی
- انتخاب واژه از فهرست
- تب مشخصات منبع
- تب توضیح فرایند ورود و نمایش اطلاعات
- بخش‌های بازشونده برای کاربرد، مثال، شماتیک، تلفظ و شاهد منبع
- کپی اصطلاح و معنی
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## دقت و محدودیت‌ها

عبارت‌های انگلیسی از صفحه اول سند گرفته شده‌اند. ترجمه‌های فارسی، مثال‌ها و نکات آموزشی برای این پیش‌نمایش تدوین شده و وضعیت آن‌ها «ترجمه نمونه؛ نیازمند بازبینی متخصص» است. این سند واژه‌نامه عمومی دریایی مرکز اسناد شناورهاست، نه استاندارد جامع مهندسی دریایی.

این پیش‌نمایش یک فایل HTML ایستا است و داده‌ها در خود صفحه قرار دارند. بانک اطلاعاتی آنلاین، پنل بارگذاری، پردازش خودکار PDF، OCR، ورود کاربران و هوش مصنوعی در این نمونه فعال نیستند. تب «نحوه کار» مراحل ثبت دستی همین سه مدخل را توضیح می‌دهد و ادعای پردازش زنده فایل ندارد.

## اجرا

فایل `index.html` را مستقیماً با مرورگر باز کنید؛ نصب نرم‌افزار یا کتابخانه نیاز نیست.
